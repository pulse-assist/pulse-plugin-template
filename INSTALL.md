# Установка плагина «Пример плагина»

Инструкция для агента Пульса после `pulse plugins install …`. Пройди её целиком, по шагам.
(Шаблон: агент-разработчик заменяет разделы под свой плагин, сохраняя структуру.)

## 1. Проверь, что плагин запустился

```bash
pulse plugins list                     # у example — status: running
pulse example --help                   # команды плагина
```

Если status: error — `pulse plugins logs example --lines 80`, расскажи владельцу, что в журнале, и остановись.

## 2. Спроси у владельца

- Каким словом приветствовать его на странице «Сводка»? (по умолчанию — «Привет»)
- При каком числе открытых задач заводить сигнал «доска завалена»? (по умолчанию — 10)
- Секрет `api_token` в примере не нужен — не спрашивай.

## 3. Настрой

```bash
pulse plugins settings example set greeting="Здравствуйте" threshold=15
```

## 4. Проверь

```bash
pulse example summary                  # числа задач, сигналов и знаний — как в Пульсе
pulse example check                    # open_tasks и threshold; signal — id, если завёл сигнал
```

## 5. Закрепи и расскажи

- `pulse plugins pin example summary` — если владелец будет часто открывать сводку.
- Ответ владельцу: что установлен «Пример плагина» (версия), в меню «Плагины ▾» — «Сводка»,
  агентам доступны `pulse example summary` и `pulse example check`, какие настройки заданы.
